# HIT140 – Foundations of Data Science
## Assessment 3: FIFA World Cup 2026 Regression Analysis

This repository contains the Python code, datasets, and visualisations for HIT140 Assessment 3 at Charles Darwin University.

The project includes two regression tasks:

- **Regression 2.1:** Predicting goal differences between teams using eight explanatory variables.
- **Regression 2.2:** Predicting goals scored by an individual team using eight explanatory variables and Ridge Regression.

**Tools:** Python, Pandas, Scikit-learn, Matplotlib, and Jupyter Notebook.

**Contents:** Python scripts, Jupyter notebooks, CSV datasets, generated graphs, and model results.

**Purpose:** Academic analysis of football match outcomes using regression techniques.
